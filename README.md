# Students Management System - CRUD Application

A modern Laravel CRUD application with Form Request validation, built as **Task 3** for the **Barakah TechLabs** PHP Laravel Engineer Internship.

## 🚀 Features

- ✅ **Create** new students with validation
- ✅ **Read** all students in a modern dashboard
- ✅ **Update** student information
- ✅ **Delete** students with confirmation
- ✅ **Form Request Validation** (custom rules & messages)
- ✅ **Modern UI/UX** with Bootstrap 5 + Glassmorphism
- ✅ **Responsive Design** for all devices
- ✅ **Statistics Dashboard** (Total students, courses, weekly additions)

## 🛠️ Tech Stack

- **Backend:** PHP 8.2, Laravel 12
- **Database:** MySQL
- **Frontend:** Blade Templating, Bootstrap 5, Bootstrap Icons
- **Validation:** Laravel Form Request Classes
- **Version Control:** Git & GitHub

## 📋 Requirements

- PHP >= 8.2
- Composer
- MySQL
- XAMPP / Laragon
